# Provenance and editorial choices

This repository is a curated proof package. The complete investigation,
including abandoned approaches, original filenames, discovery programs, and
historical reports, remains at the pinned
[research-archive commit](https://github.com/hrfueinade-pixel/Cyclic-multiset-sum-proof-test/tree/83892af4a9fa3aea516eb17af01bbb8b9c8467ba)
in this repository's history. This review preserves its bytes and history.

The main proof and supporting chapters replace chronological status reports
with a dependency order. Necessary hand arguments are retained and connected;
the common-tail correction and the seven-point-before-baseline ordering are
explicit. The [source map](source-map.json) records the original names and
content hashes of the retained programs and certificate inputs. The
exposition selections are recorded in the same file. The source map is for
traceability, not an assertion that the historical text is error-free.

Checker functions have been expanded from dense generated formatting and
given descriptive filenames. Their finite algorithms and certificate
identities are retained, with stricter completion gates, a required quartic
threshold of 89, isolated generated outputs, and explicit input sets. The
public runner adds full orchestration and failure controls.

Most retained certificate bytes are unchanged. The large-forest and
interaction archives are reassembled from numbered pieces into one gzip file
each, with the original concatenated bytes preserved. The balanced-parity
reference combines only completed order records from the two source runs;
the partial timeout record is excluded. Reference reports are consistency
controls; the release reruns the underlying enumeration.

Discovery probes, duplicated checkers, superseded manifests, exploratory
certificates, broad search logs, old README material, and research targets
are omitted from this edition. Their preservation in the original archive
keeps future work recoverable while keeping this proof's actual dependencies
visible. The retained ordinary-forcing nodes are conditional and branch completely.
Unused conditional quintic-credit rules have been removed from the current
checker. See [certificate contracts](certificates.md) and the
[review record](review-status.md) for later changes to this reading edition.

For maintenance, use descriptive claim names and update the manuscript and
dependency ledger together with any changed certificate or algorithm. Run
`python verification/seal.py` after an intentional release edit, inspect the
resulting manifest changes, and then run the full fresh verification.
